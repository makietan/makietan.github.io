Android File Transfer が終了したため、代替として OpenMTP を使用する。

1. OpenMTP をインストールする

```bash
brew install openmtp --cask
```

2. Android デバイスを接続する

OpenMTP を起動し、USB ケーブルで Android デバイスを接続します。デバイス側で「ファイル転送」モードを選択する。

3. ファイルを転送する

OpenMTP の画面上で、Mac 側と Android 側のファイルを確認できます。ドラッグ＆ドロップでファイルを転送する。

以上で、OpenMTP を使った Android とのファイル転送は完了。
