## 100 MiB以上のコミットを拒否

以下を標準の `pre-commit` フックとして配置します。Node.jsを使用し、ステージされたファイルのサイズだけを調べます。既存フックがある場合は上書きせず統合してください。

```sh
#!/bin/sh
exec node <<'NODE'
const { execFileSync } = require('node:child_process');

const limit = 100 * 1024 * 1024;
const git = (...args) =>
  execFileSync('git', args, { encoding: 'utf8' });

try {
  const paths = git(
    'diff', '--cached', '--name-only', '--no-renames',
    '--diff-filter=AM', '-z'
  ).split('\0').filter(Boolean);

  let rejected = false;

  for (const filename of paths) {
    const size = Number(git('cat-file', '-s', `:${filename}`));

    if (!Number.isSafeInteger(size) || size < 0) {
      throw new Error('ファイルサイズを取得できませんでした');
    }

    if (size >= limit) {
      console.error(
        `コミット拒否: ${JSON.stringify(filename)} ` +
        `(${(size / 1024 / 1024).toFixed(1)} MiB)`
      );
      rejected = true;
    }
  }

  process.exitCode = rejected ? 1 : 0;
} catch (error) {
  console.error('サイズ検査に失敗しました:', error.message);
  process.exitCode = 1;
}
NODE
```

標準の配置先と、実行権限を付けるコマンドです。

```bash
git rev-parse --git-path hooks/pre-commit
chmod +x "$(git rev-parse --git-path hooks/pre-commit)"
```

`core.hooksPath` を設定済みの場合は、その配置先を使用します。フックは `git add` 時の取り込みまでは防げず、コミット時に拒否します。
