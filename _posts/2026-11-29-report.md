クイックアクションで音量正規化を行うスクリプトの例です。

`シェルスクリプトを実行` をワークフローに追加して、以下のスクリプトを設定します。

```bash
export PATH=/opt/homebrew/bin:/usr/local/bin:$PATH

# 選択されたすべてのファイルに対してループ処理を実行
for input_file in "$@"; do
    # 入力ファイル存在確認
    if [ ! -f "$input_file" ]; then
        echo "Error: file not found: $input_file"
        continue
    fi

    # 出力ファイル名を生成
    output_file="${input_file%.*}_normalized.${input_file##*.}"

    # 目標値
    target_peak_db="-1.0"
    target_mean_db="-16.0"

    analysis_log="$(ffmpeg -hide_banner -i "$input_file" -vn -af volumedetect -f null - 2>&1)"

    max_volume_db="$(printf '%s\n' "$analysis_log" | sed -n 's/.*max_volume: \([-0-9.]*\) dB.*/\1/p' | tail -n 1)"
    mean_volume_db="$(printf '%s\n' "$analysis_log" | sed -n 's/.*mean_volume: \([-0-9.]*\) dB.*/\1/p' | tail -n 1)"

    if [ -z "$max_volume_db" ] || [ -z "$mean_volume_db" ]; then
        echo "Error: could not parse max_volume/mean_volume from ffmpeg output for $input_file"
        continue
    fi

    gain_by_peak_db="$(awk -v target="$target_peak_db" -v maxv="$max_volume_db" 'BEGIN { printf "%.2f", target - maxv }')"
    gain_by_mean_db="$(awk -v target="$target_mean_db" -v meanv="$mean_volume_db" 'BEGIN { printf "%.2f", target - meanv }')"

    volume_adjust_db="$(awk -v gp="$gain_by_peak_db" -v gm="$gain_by_mean_db" 'BEGIN { if (gm < gp) printf "%.2f", gm; else printf "%.2f", gp }')"

    audio_filter="acompressor=threshold=-24dB:ratio=3:attack=15:release=250:makeup=6,volume=${volume_adjust_db}dB,alimiter=limit=0.95"

    # 音量正規化（映像はそのまま、音声のみ再エンコード）
    ffmpeg -hide_banner -y -i "$input_file" -c:v copy -af "$audio_filter" "$output_file"
done
```

`~/Library/Services/` に保存すると、クイックアクションとして利用可能です。
