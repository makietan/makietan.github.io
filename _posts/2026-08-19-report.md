なんか `yt-dlp` が `ERROR: unable to download video data: HTTP Error 403: Forbidden` ばかり吐くようになった。

てか、`2026.07.04` にしてからちらほら発生していた

更新したら治るかなと思ったので HEAD 版に更新してみた。

```bash
brew uninstall yt-dlp
brew install --HEAD yt-dlp
```

これで　`yt-dlp` プロジェクトの最新のコミットがインストールされる。

新しい stable 版が出るまでのつなぎとして HEAD 版を使うのはありだと思う。

その場合は、 HEAD 版をアンインストールして、 stable 版をインストールし直す必要がある。

```bash
brew uninstall yt-dlp
brew install yt-dlp
```

ちなみにハッシュ確認にするには

```bash
brew info yt-dlp
```
