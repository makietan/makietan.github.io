## はじめに

センシティブな投稿をしていないにもかかわらず、Xがセンシティブな内容が含まれていると誤って判断し、警告を表示してくる事がある。

AIの判定とユーザーへの伝達の間に人が軽くチェックすべきなのだが何もしていないのだろう。

> センシティブな内容が含まれている可能性があるため、最近のポスト1件以上に警告を表示しています。この警告が何らかの手違いと思われる場合は、異議申立てできます。

無実のユーザーを犯罪者かのように仕立て上げるのは、AIの判定をそのまま鵜呑みにしているバカだからであり、

AIの判断を人がチェックすることなくユーザーに伝えてしまうことは、非常におろかで危険な行為である。

X（旧：Twitter）って本当にゴミサービス。

この程度の修正すらできないのか、Xの開発者は。

## 3. 異議申し立てを送信する

ここまでたどり着いたら、あとは異議申し立てを送信するだけである。

`センシティブな内容（ヌード、性的なコンテンツ、暴力、グロテスクな画像/動画、ヘイトの象徴） 異議申し立て 例文` で検索すると、異議申し立ての例文が出てくるので、それを参考にして送信する。

Gemini によると以下のような回答が得られた。

### 📋 状況別・異議申し立ての例文

該当する状況のテキストをコピーし、`[ ]` の部分を書き換えてご使用ください。

#### 1. 衣服を着用している（ヌード・性的コンテンツの誤判定）

```
当該ポスト（投稿）はコミュニティガイドラインに違反していません。画像に写っている人物は[水着 / コスチューム / スポーツウェア]を適切に着用しており、ヌードや性的なコンテンツには該当しません。AIによる誤判定の可能性が高いため、再審査と制限の解除をお願いいたします。
```

#### 2. アニメ・イラスト・芸術作品の場合

```
本投稿の画像は、一般的な[ファンアート / イラスト / 芸術作品]であり、性的な描写やグロテスクな表現、暴力を助長する意図は一切含まれておりません。健全な創作活動の一環です。お手数ですが、人間による目視での再審査をお願いいたします。
```

#### 3. フィギュア・おもちゃ・商品画像の場合

```
該当の画像は、市販されている[フィギュア / キャラクターグッズ]の紹介写真です。成人向け商品ではなく、全年齢対象の一般的な玩具であり、センシティブな内容には該当しません。誤判定だと思われますので、制限の解除をお願いいたします。
```

#### 4. 風景・植物・料理・日常写真の場合

```
本投稿の写真は、日常の[料理 / 風景 / ペットの日常]を撮影したものです。暴力、ヌード、ヘイトの象徴など、センシティブな要素は一切含まれていません。完全に誤判定であるため、お手数ですが確認と制限の解除をお願いいたします。
```

#### 5. 理由が不明・広く使える汎用文

```
当該ポストを確認いたしましたが、ヌード、性的コンテンツ、暴力、グロテスク、ヘイトの象徴のいずれにも該当しない健全な内容です。コミュニティガイドラインを遵守しております。AIによる誤判定だと思われますので、再審査をお願いいたします。
```

### 💡 異議申し立てを成功させるための注意
- **感情的にならない**：怒りや不満は書かず、「ガイドラインを遵守している」という事実のみを敬語で伝えます。
- **「人間による目視」を促す**：自動判定（AI）の誤りを指摘し、人間のスタッフに確認してもらうよう書き添えると効果的です。
- **英語での送付も検討する**：プラットフォームの運営元（X社など）が海外の場合、英語で申請すると処理が早いケースがあります。

### 🌐 英語の例文（汎用）

```
My post does not violate the community guidelines. It does not contain any nudity, sexual content, violence, or hate speech. It is a completely appropriate [photo / illustration]. Please review it manually and remove the restriction. Thank you.（私の投稿はガイドラインに違反していません。ヌードや性的コンテンツ、暴力、ヘイトスピーチは含まれておらず、適切な写真/イラストです。手動での再審査と制限解除をお願いします。）
```

## おわりに

Xによる非道なセンシティブ判定に対して、異議申し立てを行うことで、誤判定の修正を促すことができます。AIの判断は便利ですが、完全ではありません。ユーザーとしては、自分の権利を守るために積極的に行動することが重要です。
