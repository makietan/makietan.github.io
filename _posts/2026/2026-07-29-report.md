久々に **Dependabot** を使おうとしたら、以下のようなメッセージが表示されて更新が止まってしまいました。

## 表示されたメッセージ

:warning:  **Dependabot updates are paused**

We noticed you haven't used Dependabot in a while, so we've paused automated Dependabot updates for this repository.

To resume updates, merge a Dependabot pull request or use `@dependabot rebase`.. See open Dependabot pull requests or learn more about pausing of activity.

### 日本語訳

:warning:  **Dependabotの更新は一時停止されています**

しばらくDependabotを使用していないことがわかったため、このリポジトリの自動Dependabot更新は一時停止されました。

更新を再開するには、Dependabotのプルリクエストをマージするか、`@dependabot rebase` を使用してください。オープン中のDependabotプルリクエストを確認するか、アクティビティの一時停止について詳しく学んでください。

記事によると90日間更新がないと自動的に更新が停止されるみたい。

また、更新を再開するには、Dependabotのプルリクエストをマージするか、`@dependabot rebase` を使用する必要があるとのこと。

## まとめ

Dependabotの更新が一時停止されたときは、以下のいずれかの方法で更新を再開することができます。

- Dependabotのプルリクエストをマージする
- `@dependabot rebase` を使用する

一時停止されるのは90日間更新がない場合なので、定期的にDependabotを使用することで自動的に更新が停止されることを防ぐことができます。
