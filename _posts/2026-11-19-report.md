ripgrep は grep より高速で、コマンドもわりとシンプル。

```bash
rg 検索文字列
```

ripgrep はデフォルトで `.gitignore` に従うため、不要なファイルを検索対象から除外できる。
また、正規表現を使った高度な検索も可能。
例えば、特定の拡張子のファイルだけを検索する場合は以下のようにする。

```bash
rg 検索文字列 --glob "*.拡張子"
```

## インストール

```bash
brew install ripgrep
```

## 使い方の例

```bash
# カレントディレクトリ以下の全ファイルから "example" を検索
rg example

# 特定の拡張子のファイルだけを検索
rg example --glob "*.txt"

# ディレクトリを指定して検索
rg example path/to/directory

# 検索結果を逆順で表示
rg example --sort path:desc
```
