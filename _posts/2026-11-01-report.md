うっかり間違えてコミットしてしまった場合に、著者情報を書き換えるのをアカウント名を引数にするだけで簡単に行うことができる。

これを `.gitconfig` の `[alias]` セクションに追加する。

```shell
rewrite-author = "!f() { \
    FILTER_BRANCH_SQUELCH_WARNING=1 git filter-branch -f --env-filter \" \
        GIT_AUTHOR_NAME='$1'; \
        GIT_AUTHOR_EMAIL='$1@users.noreply.github.com'; \
        GIT_COMMITTER_NAME='$1'; \
        GIT_COMMITTER_EMAIL='$1@users.noreply.github.com'; \
    \" HEAD; \
}; f"
```
