**残った動画データの容量を回収したいなら、他のGit処理を止めてから、次を順番に実行してください。**

```bash
git reflog expire --expire-unreachable=now --all
git prune --expire=now
git gc --prune=now
```

- `git prune` は、再圧縮せず、参照されなくなった未パックのオブジェクトを削除します。
  - `--expire=now` は、通常なら猶予期間中は残る到達不能な未パックオブジェクトもすぐ削除対象にします。ブランチやタグ、残っているreflogから参照されるオブジェクトは削除されません。

- `git gc` は、参照されなくなったオブジェクトをまとめて削除し、ディスク容量を回収します。
  - `--prune=now` は、`git gc` による不要オブジェクト削除の猶予期間をなくし、到達不能な未パックオブジェクトをすぐ削除します。通常の `git gc` では一定期間残しておくため、別のGit処理と同時に実行すると必要なオブジェクトまで削除するおそれがあります。

注意点は2つです。
- 動画だけでなく、他の到達不能な旧履歴も削除対象になり、復旧できなくなります。
- 動画がパック内にある場合や、別ブランチ・タグから参照されている場合、その容量は回収されません。
