mpv は、軽量で高機能なメディアプレイヤー。

設定次第で自分好みにカスタマイズできるため、便利な設定をいくつか書いておく。

## 導入方法

Homebrew でのインストールが一番手っ取り早い。

```bash
brew install mpv
```

## おすすめ設定

まずは、基本的な設定です。`~/.config/mpv/mpv.conf` に以下の内容を追加すると便利です。

```conf
# 視聴履歴を保存
save-watch-history=yes
# ドラッグ＆ドロップでプレイリストに追加
drag-and-drop=append
# スクリーンショットの保存先（ただし、 `screenshot-template` で絶対パスを指定されると無視される）
screenshot-dir="~/Pictures/mpv"
# スクリーンショットのファイル名の設定
screenshot-template="%{media-title:%F}-%p"
```

### 視聴履歴を保存

#### watch_history.jsonl

`save-watch-history=yes` を設定すると、視聴履歴が `watch_history.jsonl` に保存される。

```json
{"time":1793790129,"path":"https://tver.jp/episodes/ep0204209g","title":"孤独のグルメ Season4 第4話 東京都八王子市小宮町のヒレカルビとロースすき焼き風"}
{"time":1793790117,"path":"https://tver.jp/episodes/epu1x1zwo1","title":"孤独のグルメ Season4 第5話 愛知県知多郡日間賀島のしらすの天ぷらとたこめし"}
```

- time: 視聴した時間（UNIXタイムスタンプ）
- path: 視聴した動画のパス（URLやローカルファイル）
- title: 動画のタイトル

### ドラッグ＆ドロップでプレイリストに追加

`drag-and-drop=append` を設定すると、ファイルをドラッグ＆ドロップした際にプレイリストへ追加される。

これを設定しておくと、1つのプレイヤーで複数の動画を連続して再生する際に便利。

今のところ、TVer と YouTube の動画をドラッグ＆ドロップで追加できる。

### スクリーンショットの保存

```conf
screenshot-dir="~/Pictures/mpv"
screenshot-template="%{media-title:%F}-%p"
```

`screenshot-dir` と `screenshot-template` を設定しておくと、スクリーンショットの保存先やファイル名を自分好みに変更できる。

`%{media-title:%F}` は動画のタイトルをファイル名に含めるための書式。

`%p` は現在の再生時刻。

絶対パスを指定した場合、`screenshot-template` で絶対パスが指定されると `screenshot-dir` は無視される。
